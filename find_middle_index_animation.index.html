Find Middle Index

แอนิเมชันอธิบายการหา index ที่ผลรวมด้านซ้ายเท่ากับผลรวมด้านขวา

ผลรวมทั้งหมด (sum)16
ผลรวมซ้าย (l)0
ผลรวมขวา (r)16
กำลังตรวจ index—
ตำแหน่งที่กำลังตรวจ ฝั่งซ้าย ฝั่งขวา พบ Middle Index

เกิดอะไรขึ้นในขั้นตอนนี้?

เริ่มจากคำนวณผลรวมของ Array ทั้งหมด
เงื่อนไข: l == rขั้นตอน 0

โค้ดที่กำลังทำงาน

int sum = 0; for (int num : nums) sum += num; int l = 0, r = sum; for (int i = 0; i < nums.size(); i++) {   r -= nums[i];   if (l == r) return i;   l += nums[i]; } return -1;
